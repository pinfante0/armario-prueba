¿Generan lo mismo Python y JavaScript?

Un tablero no se guarda: se genera desde una plantilla, un armario y una semilla. herramientas/resolver.py demuestra que todos los tableros tienen solución y una sola, pero lo demuestra sobre los tableros que genera Python. Si el navegador generase otros, esa demostración no diría nada sobre el juego que alguien juega.

Esta página vuelve a generarlos aquí y compara. Las huellas de Python están en tableros_esperados.json, y las escribe python herramientas/comparar_generadores.py, que además abre esta página sin ventana y lee el resultado, para que la comprobación se pueda encadenar antes de un commit.
